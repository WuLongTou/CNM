# AI 生成 Sprite Sheet 最佳实践（斩妖录实战沉淀）

适用：Gemini / Nano Banana 等对话式生图 AI。核心矛盾是 **AI 没有像素级排版能力，
但管线需要精确切帧**——所以一切实践围绕「prompt 里给足锚点 + 后处理兜底容错」。

## 一、Prompt 四段式模板（可直接复制）

```
【风格块】2D游戏美术，简笔画速写本风格，马克笔手绘感：米白纸面质感的色块填充
配炭棕色(#332e29)描边，造型由少量平滑闭合的色块组成，Q版二头身比例，无渐变、
无阴影晕染、无纹理，眼睛是纯黑墨点加一个小白高光，妖物有一对血红发光的眼睛
(#c0392b)。白色纯色背景。

【角色块】单只妖物/角色的具体设定（体型、材质、特征件、表情气质）。

【动作块】N个连续动作帧，帧间动作用箭头串联（蓄力→发力→收回→回正）；
循环动画首尾帧姿态应一致（walk/idle），非循环动画最后帧为定格（death）。

【负面块】画面只包含角色/物品本身：不要地面线、不要横线、不要边框、不要文字、
不要数字标注、不要阴影、不要网格线。所有帧严格面朝右，头部和身体朝向一致，
角色在每帧中大小一致、动作基线一致。
```

要点：
- **帧数写明数字并逐帧描述动作**，只说「攻击动画」会得到随机帧数；
- **朝向必须显式声明**（AI 默认可能混朝向，第 1-2 帧朝左是常见翻车点）；
- **负面清单必带「不要地面线」**——模型酷爱画一条贯穿基线，会把所有帧粘连
  导致投影切帧失败（实战首翻车点）；
- **图标/网格类**改为：「一张 R行×C列 的网格图，共 N 个物品，按行排列，
  每格一个，格子等大、间距清晰、互不重叠」，并逐个编号描述内容；
- **角色一致性**用对话续画：同会话先出定妆照，再「保持这只角色完全一致，
  画出 XX 动作的 6 帧 sheet」；跨会话无法保持角色一致。

## 二、排版规格（切帧管线的硬约束，斩妖录）

| 资产 | 源图布局 |
|---|---|
| 玩家动作（walk/attack/dash/hurt/death） | 96×96 cell 横排紧贴（帧数 = 格数），透明 PNG |
| 妖物动作/妖王形态 | 128×96 cell 横排，格间 ≥28px 透明间隔，瘦长全身像（切帧后强制拉成 43×96，画胖了会被压扁） |
| 图标/物件 | 网格图，后处理按格切 + trim + 256×256 透明 PNG |
| 地面整图 | 16:9，JPG，无透明要求 |

AI 出图不需要精确像素——**结构对了即可**（横排一行 / 规则网格），
尺寸由后处理归一化。白底 JPG 也可以（后处理泛洪去底），透明 PNG 更好。

## 三、后处理管线（.workwork/gemini-gen/）

```
gen_one.py   驱动浏览器生成（新会话→填prompt→发送→轮询→下载按钮→接文件）
batch.py     清单驱动批量 + 断点续跑（state.json）
post.mjs     后处理：<raw> <kind> <id> [jsonArgs]
             kind = enemy|boss|player3|grid|ground
```

post.mjs 关键算法（复用 tools/lib/imageops.mjs）：
1. **边缘泛洪去底**：只清除与图边连通的近白像素，内部纸白填充安全
   （勿用全局白像素剥离，会蚀穿浅色填充）；
2. **裸线移除**：高密度行带中「上下±10px 均为空白」的像素才清除——
   地面线消失，跨越线条的实体内容（如尾巴）保留；
3. **分帧**：投影分割优先，帧数不符时等分网格兜底（模型排帧近似等距）；
4. **归一化**：妖物 trim→拉伸 43×96 居中 96 cell；图标 trim→256 contain；
   按上文规格重组源图，产物直接可被 `npm run assets:sync` 切帧。

## 四、QC 清单（入 assets-src 前逐张目检）

- [ ] 帧数对（缺帧宁缺勿滥：view 层按实际帧数播放，但视觉抽帧会卡顿）
- [ ] 无地面线/文字/边框残留（脚本检测：单行连续内容 >50% 宽即疑似横线）
- [ ] 朝向一致（全部面朝右；个别帧反朝向 → 该帧弃用或重生成）
- [ ] 风格一致（同种妖物的 walk 与 attack 放一起对比；色偏明显的重生成）
- [ ] 去底干净（白边残留检查：紧邻透明区的浅色像素应已半透明化）
- [ ] 图标网格切分正确（每格内容完整、无邻格入侵）

## 五、已知翻车点与对策

| 翻车 | 对策 |
|---|---|
| 地面线贯穿粘连帧 | prompt 负面清单 + post.mjs 裸线移除（双保险） |
| 帧间尾巴接触粘连 | 等分网格兜底切帧（模型排帧近似等距） |
| 帧朝向不一致 | prompt 显式「严格面朝右」+ QC 弃用帧 |
| 一次生成返回多张候选 | 逐张 QC 择优；下载按钮只下当前选中张 |
| 跨会话角色不一致 | 同会话续画；或 prompt 里角色描述足够具体 |
| 免费配额限流 | state.json 断点续跑；错峰再跑 |
| 风控拒绝（Request Denied） | 换措辞重试；游戏美术素材通常安全 |
