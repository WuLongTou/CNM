# 妖物贴图第二批生成提示词（瘴妖/唤灵/弩妖/浮灯/铁傀/甲妖/蛟/蚀群）

> 用法：逐条复制进 Gemini（同一会话内同一妖物的 walk+attack 连续生成以保持角色一致），
> 下载后按文末后处理命令入库。风格块四段式与 QC 清单见
> `.agents/skills/sprite-sheet-ai/SKILL.md`。排版规格：妖物 128×96 cell 横排、
> 格间 ≥28px 透明间隔、瘦长全身像（切帧后拉成 43×96，画胖会被压扁）。

## 通用风格块（每条 prompt 开头都要带）

```
2D游戏美术，简笔画速写本风格，马克笔手绘感：米白纸面质感的色块填充
配炭棕色(#332e29)描边，造型由少量平滑闭合的色块组成，Q版二头身比例，无渐变、
无阴影晕染、无纹理，眼睛是纯黑墨点加一个小白高光，妖物有一对血红发光的眼睛
(#c0392b)。白色纯色背景。
```

## 通用负面块（每条 prompt 结尾都要带）

```
画面只包含妖物本身：不要地面线、不要横线、不要边框、不要文字、
不要数字标注、不要阴影、不要网格线。所有帧严格面朝右，头部和身体朝向一致，
每帧大小一致、动作基线一致。
```

## 后处理命令（生成图下载后）

```bash
# 每张生成图（假设下载到 .workwork/gemini-gen/raw/）：
node tools/lib/post.mjs .workwork/gemini-gen/raw/<file>.png enemy <enemy_id>_walk
node tools/lib/post.mjs .workwork/gemini-gen/raw/<file>.png enemy <enemy_id>_attack
# 产物自动入 assets-src/sprites/enemies/sheets/，然后：
npm run assets:sync && npm run dev
```
