# 试玩指南（R187b 手感转向验证版）

> 本指南面向项目所有者：5 分钟上手体验「手感转向」十轮改动的成果，
> 并按末尾模板反馈——每条反馈都能直接映射到 config.ts 的调参旋钮。

## 启动

    npm install   # 首次
    npm run dev   # http://localhost:5173

## 本轮改了什么（对照体验）

| 维度 | 改动 | 体验点 |
|---|---|---|
| 妖潮密度 | 世界缩小 25% + 上限上调 | 开局 10 秒内成群逼近（不再空旷） |
| 走位压力 | 敌速全表 ×1.25 + 阶数爬坡 | 快速妖（魅影/蚀群）会逼你用冲刺 |
| 难度曲线 | Act1 妖伤六折温和热身 | 首分钟不会秒杀，Act2 起爬升 |
| 升级节奏 | 符箓保底 20 杀必掉玩家脚边 | 首个三选一 ~20-30s 必到 |
| 连杀奖励 | 10/25/50 连杀掉回春丹 | 贴脸割草有续航回报 |
| 贴图 | 前 6 只妖物 Gemini 手绘风 | 妖物图鉴可看胶片条 |
| 反馈 juice | 击杀音高爬升/连杀屏显/治疗绿字/妖王凝固 | 割草变奏 + 里程碑戏剧感 |

## 体验重点（按时间线）

1. **0-10s**：妖潮围拢速度是否舒适？（太挤/太空都算反馈）
2. **~20-30s**：首个三选一是否准时到达？卡面武器图标缺失属已知（图标待生成）
3. **5 连杀起**：连杀计数与音高爬升是否有感觉？
4. **10 连杀**：回春丹是否掉落在击杀位置？
5. **45s / 90s（第 2/5 阶妖王）**：妖王现世的 180ms 凝固 + 血红横幅是否有戏剧感？
6. **Act2 起（150s）**：难度爬升是否平滑？

## 反馈模板（直接复制填写）

    难度：Act1（前 150s）偏易/合适/偏难；Act2-3 爬升 偏易/合适/偏难
    手感：移动/攻击/冲刺/受击 有无不跟手或缺失反馈的地方
    节奏：升级/连杀/妖王 出现频率 偏快/合适/偏慢
    视觉：贴图/粒子/数字 可接受或指出最扎眼处
    其他：任何「如果能……就好了」

## 反馈 → 旋钮映射（我会据此调参）
