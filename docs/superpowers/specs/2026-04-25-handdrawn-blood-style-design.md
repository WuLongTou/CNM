# 僵尸大战 — 手绘血色涂鸦风格设计

## 视觉基调

**核心概念**：手绘素描本 + 血色暗夜。游戏区域保持暗红恐怖氛围，所有 UI 元素以"便签纸条"形式浮在画面上，呈现铅笔/炭笔手绘质感。

### 色彩方案

| 用途 | 色值 | 说明 |
|------|------|------|
| 战场底色 | `#140a0a` | 深暗红黑 |
| 战场中间调 | `#3d1a1a` | 暗红棕 |
| 战场强调色 | `#c0392b` | 鲜红 |
| 战场高亮 | `#e74c3c` | 亮红 |
| 便签纸底色 | `#f0e8e8` | 淡红灰白 |
| 便签中间调 | `#e0d0d0` | 浅粉灰 |
| 便签文字 | `#4a1a1a` | 深红棕 |
| 便签边框/装饰 | `#8b3a3a` | 中红棕 |
| 便签次要文字 | `#5a3a3a` | 灰红棕 |
| 稀有度 - 稀有 | `#c0392b` | 红色角标 |
| 稀有度 - 史诗 | `#f39c12` | 金色角标 + 发光 |

### 视觉对比

- **暗色战场**（深红黑） vs **浅色便签**（淡红灰白）= 强烈的视觉层次分离
- 所有便签元素带纸阴影（`box-shadow: 2-3px 2-3px 4-6px rgba(0,0,0,0.4-0.5)`）
- 每个便签微旋转 ±0.3°~2.5°，模拟随意贴上的手写感

## HUD 布局

采用极简素描本风格，信息压缩到最少：

### 元素位置

| 位置 | 内容 | 样式 |
|------|------|------|
| 左上 | 血条 | 便签纸条，红色墨水填充进度条，手绘边框 |
| 右上 | 回合数 + 分数 | 小便签，手写数字 |
| 左下 | 属性（ATK/CRIT/SPD/Lifesteal/Interval） | 虚线边框便签，紧凑排列 |
| 右下 | 僵尸计数 | 实线边框便签 |
| 顶部居中 | Boss 血条（仅 Boss 战显示） | 长条便签，红色填充 |

### 便签样式规范

- 背景：`#f0e8e8`
- 边框：`1.5px solid #8b3a3a`（实线）或 `1px dashed #8b3a3a`（虚线）
- 内边距：`4-8px`
- 旋转：`±0.3°~0.8deg`（HUD），`±1°~2.5°`（武器选择卡牌）
- 阴影：`2-3px 2-3px 4-6px rgba(0,0,0,0.4-0.5)`
- 字体：使用手写风格字体（需要确定 Godot 4 支持的方案）

## 武器选择界面

每回合结束后弹出，三张便签卡片并排展示：

### 卡片结构

```
┌─────────────┐  ┌─────────────┐  ┌─────────────┐
│  [RARE] ◄角标│  │             │  │             │
│             │  │             │  │             │
│   ⚔️ 图标   │  │   🏹 图标   │  │   🛡️ 图标   │
│             │  │             │  │             │
│  火焰之剑   │  │    长弓     │  │    铁盾     │
│ ─────────── │  │ ─────────── │  │ ─────────── │
│ ATK+12·燃烧 │  │ ATK+8·穿透  │  │ HP+30·减伤  │
└─────────────┘  └─────────────┘  └─────────────┘
                        跳过 →
```

### 稀有度视觉

- **普通**：无边框角标，白纸底色
- **稀有**：红色角标 `#c0392b`，角标微旋转 5°
- **史诗**：金色角标 `#f39c12` + 纸张边缘发光效果

### 交互

- 悬停时卡片微微放大并停止旋转
- 选中时卡片弹跳动画
- 底部"跳过 →"手写按钮

## Game Over 界面

1. 血色墨水飞溅遮罩覆盖全屏（从中心向外扩散）
2. 中央展开一张皱巴巴的红色信纸
3. 手写内容：
   - "你倒下了..."
   - 坚持回合数
   - 击杀总数
   - 本次得分
   - 历史最高分（如果是新纪录则用红色墨水标注）
4. 底部两个手写按钮："再来一次" / "退出"

---

## 暂停界面

- 半透明暗红遮罩
- 中央便签纸：手写"暂停"
- 继续游戏 / 退出 按钮

## VFX 特效

所有特效遵循手绘美术风格，不使用发光/科技感效果：

| 触发 | 效果 | 实现 |
|------|------|------|
| 玩家受击 | 红色墨水飞溅 | 红色墨点粒子从受击方向喷射 |
| 暴击 | 大范围墨水飞溅 + 纸张撕裂 | 更大粒子 + 屏幕短暂白色裂痕 |
| 僵尸死亡 | 被"橡皮擦掉"消散 | 僵尸精灵透明度渐降 + 像素抖动消散 |
| 玩家冲刺 | 铅笔速写线条 | 残影显示为铅笔描边轮廓 |
| 近战攻击 | 炭笔笔触斩击弧 | 半弧形黑色/深红色笔触 |
| 远程攻击 | 铅笔弹道线 | 细长铅笔线条轨迹 |
| Boss 出场 | 纸张剧烈抖动 + 墨水蔓延 | 屏幕震动 + 黑色墨水从四边蔓延 |
| 升级选择 | 便签纸滑入 | 三张卡牌从屏幕外滑入 |

## 音效方向

| 类别 | 风格 | 示例 |
|------|------|------|
| BGM | 低沉弦乐 + 不规则心跳节拍 | 恐怖氛围 |
| 近战攻击 | 纸张撕裂声 + 低沉钝击 | 手绘世界的物理反馈 |
| 远程攻击 | 铅笔划过纸张的唰声 | 快速、干脆 |
| 僵尸呻吟 | 铅笔摩擦声的变体 | 低频、不规律 |
| 僵尸死亡 | 橡皮擦擦除声 | 从有到无 |
| UI 交互 | 翻纸声 / 铅笔点纸声 | 轻微、清脆 |
| 玩家死亡 | 墨水瓶摔碎 + 静默 | 突然、震撼 |
| Boss 出场 | 重低音 + 纸张撕裂 | 威胁感 |

## 贴图润色

不重新制作所有贴图，在现有贴图基础上添加手绘质感：

1. **边缘处理**：给所有精灵添加不规则的铅笔描边
2. **纹理叠加**：在精灵上叠加细微的纸张纹理噪点
3. **色调统一**：将所有精灵色调向血色暗夜调色板靠拢
4. **缺失动画**：补充玩家死亡/冲刺、僵尸攻击等缺失帧

## 实施优先级

### 阶段 1：UI 皮肤化（最高优先级）
- 将现有 HUD 改为手绘便签风格
- 改造武器选择界面为便签卡片
- 改造 Game Over 为血色信纸
- 改造暂停界面

### 阶段 2：VFX 替换
- 墨水飞溅粒子替代现有受击效果
- 铅笔轨迹替代武器轨迹
- 橡皮消散替代死亡效果
- 屏幕震动 + 墨水蔓延效果

### 阶段 3：贴图润色
- 精灵描边 + 纸张纹理叠加
- 色调统一到血色暗夜调色板
- 补充缺失动画帧

### 阶段 4：音效集成
- BGM / 环境音
- 攻击 / 受击 / 死亡音效
- UI 交互音效

### 阶段 5：游戏平衡
- 测试所有武器强度曲线
- 调整僵尸难度台阶
- 打磨 Combo 手感
- Boss 战节奏调整

## 技术约束

- Godot 4.6 + C# 环境
- UI 通过代码创建（Control 节点），不使用 .tscn 场景
- 所有贴图资源放在 `assets/sprites/`
- 手写字体需要找到 Godot 4 兼容的 .ttf/.otf 资源
- 特效通过 VFXManager 统一管理
- 配色参数集中到 GameConfig.cs
