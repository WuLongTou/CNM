# 斩妖录（Web 版）

简笔画速写本风除妖生存 roguelike：扮演除妖师，在持续逼近的妖潮中存活。
TypeScript + PixiJS v8 实现的完整重写版。玩法数值对齐 C# 旧版数据表，
**主题为「斩妖」设定**：玩家是除妖师，敌人统称妖物。仓库内不含任何旧引擎工程文件。
美术为**简笔画（速写本）风格**：米白纸面世界 + 炭棕手绘线条 + 血红点缀，
全部角色与场景物件贴图由 `tools/gen-sketch.mjs` 程序化生成（seed 固定可复现），
场景与角色共用同一套视觉语言。

## 架构

```
src/
  sim/      纯逻辑层（零 DOM/渲染依赖）：状态机、开局职业、除妖师、妖物 AI、武器、伤害、
            刷怪、难度、天气、成就、结算。固定 60Hz 步长 + 种子化 PRNG → 同 seed 同输入
            同结果，vitest 直接跑。
  render/   PixiJS v8 渲染层：只读 sim 状态绘制（地面/实体/弹道/相机/帧动画）。
  ui/       DOM UI 层：HUD、欢迎、暂停、帮助、装备、合成、结算、触屏控件等（手账血色风）。
  app/      装配：主循环（固定步长累加器）、键盘+触屏输入合成、debug API、音频。
            数值表直接内聚于 sim/（config.ts 妖物三维与天气、weapons.ts 武器表、
            recipes.ts 配方，源自 C# 版数据）。
tests/
  sim/      vitest 逻辑回归。
  e2e/      Playwright E2E（完整对局闭环）。
tools/      资产管线：gen-sketch.mjs 程序化生成简笔画源图（玩家/妖物/地面），
            sync-assets.mjs 从 assets-src 生成 public/assets（剥底/切帧/atlas），
            源文件名全部中性（enemy_*）。
```

## 调试 / AI 测试 API

页面暴露 `window.__CNM__` 调试协议(exec / getEvents / sim,自动化测试与状态探查);
协议详情见 `.agents/skills/cnm-auto-test/SKILL.md`。

## 命令

```bash
node tools/gen-sketch.mjs   # 重新生成简笔画源图到 assets-src（调造型后需重跑）
npm run assets:sync         # 从 assets-src 生成 public/assets（剥底/切帧/atlas）
npm run dev                 # Vite dev server @ 127.0.0.1:5173
npm run build         # 自动先 assets:sync（prebuild）+ tsc 类型检查 + vite build
npm test              # vitest 逻辑回归
npm run e2e           # Playwright E2E（自动先 assets:sync 再起 dev server）
npm run preview       # 本地预览 dist 产物 @ 127.0.0.1:4173
```

## 构建 / 测试 / 部署

- 日常验证以 **CI 为权威门禁**（`.github/workflows/ci.yml`，push/PR 到 main 触发）：
  `npm ci` → `npm run assets:sync` → `npm test`（vitest，sim 层逻辑回归）→ `npm run build`
  （prebuild 自动执行 `assets:sync` + tsc 全量类型检查 + vite 产物）→ preview 冒烟；
  node 22/24 双档矩阵。本地提交前只跑秒级检查（`npx tsc --noEmit`，见 `AGENTS.md`），
  需要调试时再按上面的流程手动执行。
  `public/assets/` 为生成产物不入库，`npm run build` 会自动同步；
  手动同步：`npm run assets:sync`。
- e2e：`npx playwright install`（首次需安装浏览器）→ `npm run e2e`
  （Playwright，自动先 assets:sync 再起 dev server，完整对局闭环）。
  断言对帧率计时敏感（串行 + 零重试），仅本地手跑，不进 CI；
  全量 e2e 对机器负载敏感，建议空载运行（此前实测批量跑偶发超时、单跑通过，属已知特性）。
- 部署：`dist/` 为纯静态产物，由 nginx 直接托管，无服务端。默认以**根路径**
  部署（如 `https://<域名>/`）；子路径部署时构建前设置 `VITE_BASE`
  （如 `VITE_BASE=/zhanyao/ npm run build`，值需带首尾斜杠），不设则保持根路径。
  可用 `scripts/deploy.sh` 一键完成「门禁 → 构建 → 版本戳 → 推送」（属发布动作：
  发布前以 main 上 CI 全绿为准，脚本内的单测/构建用于生成并校验本次产物）：
  - `./scripts/deploy.sh` — 先跑 `npm test` 门禁，再 `npm run build`，并在
    `dist/` 写版本戳 `.deploy-version`（git describe 一行 + UTC 构建时间一行）；
  - `./scripts/deploy.sh --smoke` — 构建后起 `npm run preview` 并 curl 断言 200；
  - `SERVER=user@host REMOTE_DIR=/srv/cnm ./scripts/deploy.sh --push` —
    经 rsync 推送 `dist/` 到 nginx 托管目录；SERVER/REMOTE_DIR 必须显式给出，
    缺失时脚本直接报错退出（防误推）。

## 操作

- 移动 WASD/方向键，攻击 空格（按住连击，**全部装备武器同时齐射**），冲刺 Shift（HUD ⚡ 指示就绪）
- **开局职业**：欢迎页三选一（纯鼠标选卡，开局后锁定）——剑修（起手铁剑，伤害 +15%，
  开局即开放）/ 弓手（起手弓箭，攻速 +15%、冲刺冷却 -20%，累计击杀 50 解锁）/
  术士（起手法杖，范围 +20%、拾取半径 +50%，讨伐妖王解锁）；
  外观随职业起手武器自动对应近战/远程/法师
- **方向攻击**：近战朝移动方向挥砍（±55° 扇形判定），锥内妖物自动吸附瞄准，出手带
  突进位移——朝哪走朝哪砍；Tab 切目标已移除（吸附瞄准取代）
- **打击反馈**：妖物被打会硬直后退（速度制击退+指数摩擦）、蓄力被打断；命中音效
  随机变调、暴击高亢；死亡碎片沿受击方向飞溅
- **冲刺斩**：冲刺窗口（0.25s）中攻击 → 伤害 1.5×，近战范围 1.35× 且多一目标，
  弓+1 矢、法术+1 弹、地雷溅射 1.5×
- **完美闪避**：冲刺窗口中被妖物攻击/自爆/弹道/蛟冲撞命中 → 免伤，妖物与敌弹
  时缓 0.9s（0.45×），自身 3s 内伤害 1.3×
- **分幕与终局**：每 150s 推进一幕（共 4 幕），妖潮密度逐幕翻倍、精英潮渐起；
  第 13 威胁阶终幕妖王降临，击杀即通关（Victory 结算金币 ×1.5，可继续无尽讨伐）
- **讨伐难度**：欢迎页三档（纯鼠标切换，开局后锁定）——平妖 / 伏魔（通关解锁）/
  镇狱（通关伏魔解锁）；高难度妖物血伤更高、金币更多，通关即开下一档
- **威胁预告与复盘**：威胁阶推进全服通告，HUD 显示进阶倒计时；陨落/通关结算
  附复盘行（精英讨伐 · 最高连击 · 收集武器）
- **妖潮异变**：开局 100 秒后每 130 秒突发事件（横幅预告）——妖群合围 /
  精锐现身 / 宝藏显形 / 宝妖游荡 / 庙会开市（25 秒内香火龛半价）五者轮转，
  紧张与释放交替；宝妖只逃不打，15 秒内追杀可爆精英箱 + 符箓，超时逃走
- **符箓词条**：升级三选一除伤害/攻速/范围外，含质变词条——多重（多目标/多发）、
  连锁、穿透、淬毒、冰缓、会心、溅射（按武器类型过滤有效词条）；报价不满意可
  R 重抽（每局 2 次）、X 跳过（回复 15 生命）或 4 / 5 / 6 放逐对应卡
  （移除该组合本局不再出现，每局 1 次，并重补一张）
- **永久升级**：陨落后用结算金币购买跨局成长——体魄/杀伐/疾风/聚灵/点金/
  回春 6 维，价格 50×（等级+1），下一局开局即生效
- **妖王弹幕**：妖王周期向四周放环形径向弹（阶段越高越密；起始角逐轮黄金角
  旋转呈螺旋漂移，狂暴 3 阶追加慢速内环），头顶血条走屏幕顶部大条
- **攻击预警**：妖物近战有 0.35s 蓄力前摇（定身+头顶！），走出范围即打空；
  脚下灰圈 = 你的攻击范围，圈内妖物脚下有血红标线；命中会把妖物打退
- **濒危与死因**：血量低于 35% 屏幕边缘泛红（一路加深）；陨落结算陈列死因
  （死于甲妖 / 精英游魂 / 游魂王 / 爆魈自爆 / 蛟冲撞 / 毒弹箭矢等）
- **重开循环**：陨落/通关结算屏按 R 直接再来一局；重开沿用上局职业与难度；
  成就页显示达成进度；HUD 存活行标注当前幕次
- **表现设置**：暂停菜单（Esc）内可关闭 震屏 / 伤害数字 / 顿帧（无障碍三开关，
  按需减负；偏好独立保存，重置战绩不丢失）
- **手柄**：插入即用（标准布局）——左摇杆/十字键移动、A 攻击（按住齐射）、
  RB/RT 冲刺、Start 暂停、右摇杆瞄准（twin-stick 边跑边打）；暂停/升级/商店
  面板内 十字键移动焦点、A 确认、B 关闭、商店内 Y 刷新报价；
  受击/击杀/妖王现身/完美闪避有震动反馈（暂停菜单可关）；
  连接/断开有播报，随时拔插不中断对局
- **精英词缀**：迅捷 / 再生 / 护盾 / 爆裂（死亡自爆，别贴脸击杀）/ 狂乱（低血狂暴）/
  分裂（死后爆 2 蚀群，备溅射）/ 疾影（闪现近身，保持移动）——头顶徽标一望可辨
- **精英掉宝**：精英必掉血红宝箱——开出稀有度≥2 武器 + 1 枚符箓，值得追杀
- **回春丹**：妖物掉落绿十字药丸（普通 2%/精英 10%/妖王必掉），走近回复 12 点生命
- **制霸矩阵**：通关记录职业×难度（欢迎页公示 x/9），集齐三职业 / 满 9 格各有成就
- **种子与分享**：欢迎页查看本局种子，可填自定义种子开局练种；结算屏复制战绩单行文案
- **生涯陈列**：欢迎页展示总存活时长/累计金币/最高连击/单局击杀/精英·妖王累计与最爱职业
- **香火龛**：击杀妖物得金币（HUD 常驻），香火龛定期浮现——走近开报价
  （武器/符箓/调息/香火祝福——伤害/攻速/移速三系随机、各限一次），每笔购买后全龛涨价；
  单局消费 5 次解锁成就「散财消灾」；三誓满档通关解锁「炼狱修罗」；
  金币与结算金币两轨分立，局内花掉不吃亏
- **处决播报**：连击 10/25/50 播报、100 横幅“百连斩”（+成就）、本局首只精英播报
- **血誓契约**：欢迎页立誓加难（血战/人海/脆体，可叠加），结算分数加成，三重全立通关有成就
- **每日妖潮**：每天同一题（日期种子），欢迎页一键挑战，今日最佳分天天刷新；
  每天还有天气主题（日晴/一四雨/二六雾/五血月/三乱流）与当日变异
  （精锐频出/财神附身/妖行如风/妖潮汹涌/妖坚如铁五轮，今日行公示、历劫 x/5）；

- **图鉴金边**：妖物手账单类累计满百杀镀金，十四金解锁博物学家成就
- **进阶教练**：精英首杀 / 近祭坛双武器 / 妖王现身 / 六械齐备时给一行情境提示
  （8 秒自动消退，看见即完成使命，不打断战斗）
- **战斗信息**：妖王血条百分比、击杀百分播报与千人斩、暂停菜单本局战绩
- **武器藏珍**：武器图鉴未见过灰隐，集齐全部解锁藏珍满架成就
- **终极图鉴**：单武器升级 6 次达终极后，武器图鉴永久挂“终极”红章
- **融合图鉴**：祭坛实际炼成的配方点亮（帮助机制页公示进度），集齐六配方解锁炼金大师
- **收藏追踪**：暂停菜单聚合五条收集线进度（制霸/藏珍/终极/祭炼/金边），随时知道下一步追什么

## 性能

渲染帧率上限 60 FPS（`app.ticker.maxFPS`，高刷屏不会跑满刷新率）；sim 逻辑固定 60Hz
步长，与渲染解耦。`window.__CNM__.fps` 可读取当前帧率（E2E 有上限断言）。

## 美术（简笔画速写本风格，v2 填充式马克笔）

全部角色贴图与地面由 `tools/gen-sketch.mjs` 程序化生成，迭代造型 = 改生成器参数
后重跑 `node tools/gen-sketch.mjs && npm run assets:sync`（seed 固定，产物可复现）。
风格规范（新增资产必须沿用）：
- 绘制系统：blob() 平滑闭合色块填充 + 炭描边为主，line() 粗笔作四肢/细节；
  Catmull-Rom 平滑 + 抖动 ≤0.45（简洁 = 自信干净的线条，抖动只在边缘呼吸）；
  主体色块加白弧高光（shine 工艺）；角色脚下淡落影；
- 调色：纸白 #f5eede / 炭棕描边 #332e29 / 铅笔灰 #8a8175 / 血红点缀 #c0392b
  （妖物眼/符箓/火）；填充为哑光纸感中调色（每色通道色散 ≥0.09，且需在 1:1
  游戏比例下可辨体积——过浅会被纸底吞掉）；
- 眼睛统一「墨点 + 白高光」；妖物有血红点睛元素，玩家无红眼——敌我一望可辨；
- 布局约定：玩家 walk/attack = 96×96 cell 紧排网格（8×1/6×1）、idle = 2×2 网格；
  妖物 = 128×96 cell 水平排列留 28px 间隔（投影分割拉伸切帧）；
  欢迎页插画 = genTitle() 独立场景（800×340，复用 drawPlayer/ENEMIES 画手）；
- 管线注意：玩家/妖物源图为透明 PNG，sync-assets 对这两类跳过剥底（strip:false，
  剥底会侵蚀浅色填充），且不做水平翻转（v2 有明确朝向，面朝右 = view facing 正向）。
- 地面构图：8 个簇心的草石 marks + 一条铅笔小径，禁止均匀散点与污渍斑
  （简洁 ≠ 简陋：元素少而有序）。

AI 生图补充资产的排版规格、后处理与 QC 流程见 `.agents/skills/sprite-sheet-ai/SKILL.md`。
