# 斩妖录（Web 版）

简笔画速写本风除妖生存 roguelike：扮演除妖师，在持续逼近的妖潮中存活。
TypeScript + PixiJS v8 实现的完整重写版。玩法数值对齐 C# 旧版数据表，
**主题为「斩妖」设定**：玩家是除妖师，敌人统称妖物。仓库内不含任何旧引擎工程文件。
美术为**简笔画（速写本）风格**：米白纸面世界 + 炭棕手绘线条 + 血红点缀，
全部角色贴图由 `tools/gen-sketch.mjs` 程序化生成（seed 固定可复现）。

## 架构

```
src/
  sim/      纯逻辑层（零 DOM/渲染依赖）：状态机、除妖师、妖物 AI、武器、伤害、刷怪、
            难度、天气、成就、结算。固定 60Hz 步长 + 种子化 PRNG → 同 seed 同输入同结果，
            vitest 直接跑。
  render/   PixiJS v8 渲染层：只读 sim 状态绘制（地面/实体/弹道/相机/帧动画）。
  ui/       DOM UI 层：HUD、欢迎、暂停、帮助、装备、合成、结算、触屏控件等（手账血色风）。
  app/      装配：主循环（固定步长累加器）、键盘+触屏输入合成、debug API、音频。
            数值表直接内聚于 sim/（config.ts 妖物三维与天气、weapons.ts 武器表、
            recipes.ts 配方，源自 C# 版数据）。
tests/
  sim/      vitest 逻辑回归。
  e2e/      Playwright E2E（完整对局闭环）。
tools/      资产管线：gen-sketch.mjs 程序化生成简笔画源图（玩家/妖物/地面），
            sync-assets.mjs 从 assets-src 生成 public/assets（剥底/切帧/atlas），
            源文件名全部中性（enemy_*）。
```

## 调试 / AI 测试 API

页面加载后暴露 `window.__CNM__`（JSON 指令协议，与 Godot 旧版 cmd-port 同构）：

```js
__CNM__.exec({ id: 1, action: "status" })   // status/game_state/start/input/choose/
__CNM__.getEvents()                          //   force_combat/spawn/give/teleport/quit
__CNM__.sim                                  // GameSim 实例（深度断言用）
```

`input` 指令与真实键盘叠加、持续有效；模态打开时 sim 自动清空游戏输入（模态独占输入硬约束）。

## 命令

```bash
node tools/gen-sketch.mjs   # 重新生成简笔画源图到 assets-src（调造型后需重跑）
npm run assets:sync         # 从 assets-src 生成 public/assets（剥底/切帧/atlas）
npm run dev                 # Vite dev server @ 127.0.0.1:5173
npm run build         # tsc 类型检查 + vite build
npm test              # vitest 逻辑回归
npm run e2e           # Playwright E2E（自动起 dev server）
```

## 操作

- 移动 WASD/方向键，攻击 空格（按住连击），冲刺 Shift（HUD ⚡ 指示就绪）
- **冲刺斩**：冲刺窗口（0.25s）中攻击 → 伤害 1.5×，近战范围 1.35× 且多一目标，
  弓+1 矢、法术+1 弹、地雷溅射 1.5×
- **完美闪避**：冲刺窗口中被妖物攻击/自爆/弹道/蛟冲撞命中 → 免伤，妖物与敌弹
  时缓 0.9s（0.45×），自身 3s 内伤害 1.3×
- **妖王弹幕**：妖王周期向四周放环形径向弹（阶段越高越密；起始角逐轮黄金角
  旋转呈螺旋漂移，狂暴 3 阶追加慢速内环），头顶血条走屏幕顶部大条
- **攻击预警**：妖物近战有 0.35s 蓄力前摇（定身+头顶！），走出范围即打空；
  脚下灰圈 = 你的攻击范围，圈内妖物脚下有血红标线；命中会把妖物打退

## 性能

渲染帧率上限 60 FPS（`app.ticker.maxFPS`，高刷屏不会跑满刷新率）；sim 逻辑固定 60Hz
步长，与渲染解耦。`window.__CNM__.fps` 可读取当前帧率（E2E 有上限断言）。

## 硬约束（沿用项目 AGENTS.md）

模态页面打开时游戏快捷键必须 100% 失效；UI 快捷键绝不复用已绑定的游戏键
（WASD/Space/Shift/Tab/H/C/反引号）。

## 美术（简笔画速写本风格，v2 填充式马克笔）

全部角色贴图与地面由 `tools/gen-sketch.mjs` 程序化生成，迭代造型 = 改生成器参数
后重跑 `node tools/gen-sketch.mjs && npm run assets:sync`（seed 固定，产物可复现）。
风格规范（新增资产必须沿用）：
- 绘制系统：blob() 平滑闭合色块填充 + 炭描边为主，line() 粗笔作四肢/细节；
  Catmull-Rom 平滑 + 抖动 ≤0.6（手绘但不脏）；角色脚下淡落影；
- 调色：纸白 #f5eede / 炭棕描边 #332e29 / 铅笔灰 #8a8175 / 血红点缀 #c0392b
  （妖物眼/符箓/火）；填充为哑光纸感中调色（每色通道色散 ≥0.09，且需在 1:1
  游戏比例下可辨体积——过浅会被纸底吞掉）；
- 眼睛统一「墨点 + 白高光」；妖物有血红点睛元素，玩家无红眼——敌我一望可辨；
- 布局约定：玩家 walk/attack = 96×96 cell 紧排网格（8×1/6×1）、idle = 2×2 网格；
  妖物 = 128×96 cell 水平排列留 28px 间隔（投影分割拉伸切帧）；
  欢迎页插画 = genTitle() 独立场景（800×340，复用 drawPlayer/ENEMIES 画手）；
- 管线注意：玩家/妖物源图为透明 PNG，sync-assets 对这两类跳过剥底（strip:false，
  剥底会侵蚀浅色填充），且不做水平翻转（v2 有明确朝向，面朝右 = view facing 正向）。
